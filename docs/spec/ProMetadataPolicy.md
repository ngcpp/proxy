# Named requirements: *ProMetadataPolicy*

> Since: 5.0.0

A metadata policy chooses how a [`proxy`](proxy/README.md) refers to the functions the library generates for a facade, and how it keeps the metadata deduced from the contained type. A type `MP` meets the *ProMetadataPolicy* requirements if `typename MP::template invoker<F>` and `typename MP::template storage<M>` meet the requirements below for every function type `F` and metadata type `M` the library uses.

## Invoker

Let `F` be a function type without cv or ref qualifiers, possibly `noexcept`, and `f` be an object of a class type that identifies one function generated by the library and converts to a pointer to it of type `F*`. `typename MP::template invoker<F>` shall denote a type `I` that meets the [*ProBasicMetadata* requirements](ProBasicMetadata.md) and for which `std::is_nothrow_default_constructible_v<I>` and `std::is_nothrow_copy_assignable_v<I>` are `true`. A value-initialized `I` is empty. An `I` obtained by copy construction or copy assignment calls the function its source calls, or is empty if the source is empty. Let `ci` be an lvalue of type `const I`, `Args...` be the parameter types of `F`, and `args...` be function parameters of types `Args...`. Every expression below except the call is non-throwing.

| Expression | Semantics |
| ---------- | --------- |
| `I(f)` | Creates an invoker that calls the function `f` converts to. |
| `static_cast<bool>(ci)` | Returns `true` if and only if `ci` is not empty. |
| `ci(std::forward<Args>(args)...)` | Equivalent to `p(std::forward<Args>(args)...)`, where `p` is a pointer of type `F*` to the function `ci` calls. The behavior is undefined if `ci` is empty. |

## Storage

Let `M` be the metadata type generated for a facade and `MP`, and `P` be a contained pointer type. The library guarantees that `M` meets the *ProBasicMetadata* requirements and that `std::is_nothrow_default_constructible_v<M>` and `std::is_nothrow_copy_assignable_v<M>` are `true`. A value-initialized `M` is empty. An `M` obtained by copy construction or copy assignment holds the metadata its source holds, or is empty if the source is empty. `M` also supports the following expressions, where `cm` is a reference to `const M`.

| Expression | Semantics |
| ---------- | --------- |
| `M(std::in_place_type<P>)` | Creates the metadata deduced from `P`. |
| `static_cast<bool>(cm)` | Returns `true` if and only if `cm` is not empty. |

`static_cast<bool>(cm)` is non-throwing. `M(std::in_place_type<P>)` throws any exception thrown by constructing a reflector.

`typename MP::template storage<M>` shall denote a type `S` for which `std::is_nothrow_default_constructible_v<S>`, `std::is_nothrow_copy_constructible_v<S>`, `std::is_nothrow_copy_assignable_v<S>`, and `std::is_nothrow_destructible_v<S>` are `true`. The library default-initializes `S` and then first resets, emplaces, assigns, or destroys it, which shall be valid even if it holds indeterminate values. Let `s` be an lvalue of type `S`, `cs` be a reference to `const S`, and `cs2` be a reference to `const MP::template storage<M2>`, where `M2` is the metadata type generated for a facade that has the facade of `M` as a super. The following expressions shall be non-throwing and have the specified semantics.

| Expression | Semantics |
| ---------- | --------- |
| `s.reset()` | Makes `s` empty. |
| `s.emplace(std::in_place_type<P>)` | Makes `s` hold `M(std::in_place_type<P>)`, or calls `std::terminate` if that expression throws. |
| `static_cast<bool>(cs)` | Returns `true` if and only if `cs` is not empty. |
| `*cs` | Returns a `const M&` referring to the stored metadata. The behavior is undefined if `cs` is empty. |
| `s = cs2` | Makes `s` hold `static_cast<const M&>(*cs2)`. The behavior is undefined if `cs2` is empty. |

The library guarantees that `const M2&` is implicitly convertible to `const M&` without throwing and that `sizeof(M) <= sizeof(M2)`. A reference returned by `*cs` shall remain valid until `cs` is modified or destroyed. A storage obtained by copy construction or copy assignment shall hold the metadata its source holds, or be empty if the source is empty, and shall remain valid after the source is modified or destroyed.

## Notes

A storage that keeps `M` in place resets or emplaces it by constructing a new `M` over the old one, such as with `std::construct_at`.

An invoker is constructed from an object whose type identifies one generated function, not from a pointer value. A signing invoker, such as the one used by `compact_metadata` and `inline_metadata` under pointer authentication, therefore never signs a pointer chosen at run time.

Initializing a non-reference parameter of `F` may throw even if `F` is `noexcept`, as in a direct call.
